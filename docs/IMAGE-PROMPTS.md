# Brand image provenance

## Selmio sculpture

Asset: [selmio-sculpture.png](../public/brand/selmio-sculpture.png).

The dashboard sculpture was created with the built-in image generation tool. It is decorative brand artwork, not a rendering of financial data. This was a new text-to-image generation with no reference images and `transparent_background: false`. No model version or seed is recorded here; repeating the prompt may produce a different image.

The exact generation prompt was:

```text
Use case: stylized-concept. Asset type: premium brand artwork for Selmio, an open-source personal budgeting app, used as a square editorial illustration on an ivory dashboard. Primary request: a single beautiful abstract sculptural ribbon that folds into two interlocking soft loops, suggesting breathing room, clarity and an unfolding future. Style: highly refined tactile 3D studio render, restrained contemporary industrial-design editorial, no glossy fintech cliches. Material: matte softly translucent pale pistachio green paper/resin with one deep forest-green inner folded face, soft grain. Composition: sculpture centered with generous empty margins, no text or symbols, square image. Backdrop: seamless warm ivory #f4f3ed, soft contact shadow, gentle daylight from upper left. Palette: muted pistachio #dce8b5, forest #27483c, ivory. Avoid coins, banknotes, dollar signs, charts, arrows, plants, grids, extra objects, purple gradients, typography, watermark. Make the form distinctive, elegant and plausibly physical.
```

## Vector assets and PNG exports

The [mark](../public/brand/selmio-mark.svg), [wordmark](../public/brand/selmio-wordmark.svg), [app icon](../public/brand/selmio-app-icon.svg) and [social card](../public/brand/selmio-social.svg) are authored SVG assets. They were not generated by the image generation tool.

The [512 × 512 app icon PNG](../public/brand/selmio-app-icon.png) and [1200 × 630 social card PNG](../public/brand/selmio-social.png) were rasterized from their existing SVG sources using Sharp. No new image generation was used for those exports. Text in the social SVG uses the font families and fallbacks specified in the source; rendering can vary with installed fonts. Use the PNG for a consistent social preview.

To regenerate the PNGs from the app directory with dependencies installed:

```sh
node --input-type=module -e 'import sharp from "sharp"; for (const name of ["selmio-app-icon", "selmio-social"]) { await sharp(`public/brand/${name}.svg`).png().toFile(`public/brand/${name}.png`); }'
```
