# Selmio

**Know what fits.**

Selmio is a calm, practical name for a spending planner. Say it **SELL-mee-oh**. The name is coined; do not invent a translation or etymology. Initial web screening found no obvious finance-app conflict, but the name has not received trademark or domain clearance.

The product helps people understand a choice in the context of their commitments. Its identity should feel considered, approachable and useful. The paired shapes in the mark suggest room, balance and two pieces fitting together. The flowing curve is an illustration, not a financial result.

## Language

- Primary line: **Know what fits.**
- Supporting line: **Your money. A little more room.**
- Product description: **A local workspace for thoughtful spending.**
- Write the name as **Selmio** in prose. The supplied wordmark uses lowercase.

Use concrete, reassuring language: “Based on this plan,” “Confirm your next paycheck,” and “This purchase leaves $240 for other spending.” Show the assumption when it matters. Avoid judgment, manufactured urgency, guaranteed outcomes and claims that a forecast makes a purchase certain or safe.

## Palette

| Color | Hex | Use |
| --- | --- | --- |
| Forest | `#27483C` | Brand, primary actions, key curves |
| Pistachio | `#DDEFAB` | Highlights, selected surfaces, space around key decisions |
| Warm ivory | `#F6F6F0` | Main background |
| Ink | `#263A32` | Body text and headings |
| Coral | `#CF785F` | Small points of attention |
| Lavender | `#E9E6F2` | Secondary panels and illustration |
| Mark accent | `#A9C47F` | Existing mark's overlapping shape |

Use ink or forest text on the pale surfaces. Pistachio, coral and lavender are accents, not default small-text colors. Validate contrast in the actual UI and pair status colors with words or symbols.

## Type and layout

Use **Manrope** as the primary family. The current app self-hosts it for headings, body copy and controls. **DM Sans** is an optional companion for collateral. Use a system sans-serif fallback when these fonts are unavailable. Prefer tabular numerals for amounts and dates. Keep headings compact, labels plain, whitespace generous and decoration restrained. Self-host fonts for an offline distribution; a network-loaded font is not an offline asset.
